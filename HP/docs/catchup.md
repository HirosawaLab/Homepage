## 1. 最初に知っておくこと

### ホームページの仕組み

ホームページは「HTMLファイル」というテキストファイルでできています。
`.html` という拡張子がついたファイルをブラウザ（Chrome等）が読み取り、
見た目のあるWebページとして表示します。

```
News.html（テキストファイル）  →  ブラウザが読む  →  ニュース一覧ページが表示される
```

**つまり、News.html を編集すれば、ニュースページが変わります。**

### CSSとは

CSSはページの「見た目（色・大きさ・レイアウト）」を制御するファイルです。
`css/stylemain.css` にまとまっています。
**ニュースやメンバーの更新作業ではCSSを触る必要はありません。**

### このサイトで編集が必要なファイル

| ファイル | 編集する場面 |
|---|---|
| `News.html` | ニュース記事の追加・修正 |
| `index.html` | トップページのニュース欄 |
| `Member.html` | メンバーの追加・削除・学年変更 |
| `Album.html` | アルバム一覧への登録 |
| `album/（フォルダ名）/main.html` | アルバム個別ページの作成 |

## 2. HTMLの基本：タグとは何か

HTMLは「タグ」と呼ばれる記号で囲まれたテキストで構成されています。

### タグの形

```html
<タグ名>内容</タグ名>
```

- `<タグ名>` が「開始タグ」
- `</タグ名>` が「終了タグ」（スラッシュ `/` がつく）
- この2つで内容を挟む

**例：**
```html
<p>これは段落です。</p>
<h2>これは見出しです。</h2>
```

### よく使うタグ一覧

| タグ | 意味 | 使い方の例 |
|---|---|---|
| `<p>` | 段落（テキストのまとまり） | `<p>本文テキスト</p>` |
| `<a>` | リンク | `<a href="URL">リンクテキスト</a>` |
| `<ul>` | 箇条書きリスト（順不同） | リスト全体を囲む |
| `<li>` | リストの各項目 | `<li>項目のテキスト</li>` |
| `<img>` | 画像 | `<img src="1.jpg" alt="説明">` |
| `<time>` | 日付 | `<time datetime="2026-4-1">2026.4.1</time>` |
| `<span>` | テキストの一部に印をつける | `<span class="category">学会</span>` |

### 入れ子構造（ネスト）

タグの中にタグを入れることができます。

```html
<ul>
  <li>項目1</li>
  <li>項目2</li>
</ul>
```

`<ul>` の中に `<li>` が入っています。これを「ネスト（入れ子）」と言います。
**インデント（字下げ）はネストの深さを表しています。** 意味はありませんが、読みやすくするための慣習です。

### 属性

タグには「属性」と呼ばれる追加情報を書けます。

```html
<a href="https://example.com">リンクテキスト</a>
```

- `href="..."` が属性
- `href` は「リンク先URL」を指定する属性名
- `="..."` の中に値を書く

よく使う属性：

| 属性 | 使うタグ | 意味 |
|---|---|---|
| `href="URL"` | `<a>` | リンク先のURL |
| `src="ファイル名"` | `<img>` | 画像ファイルのパス |
| `alt="説明"` | `<img>` | 画像が表示できないときの代替テキスト |
| `class="名前"` | 多くのタグ | CSSのスタイルを適用するための名前 |
| `datetime="YYYY-M-D"` | `<time>` | 機械が読む用の日付 |

## 3. このサイトでよく使うHTMLパターン

実際のファイルに出てくるパターンを覚えることが最短ルートです。

### パターン①：ニュース記事1件分

```html
<li>
  <time datetime="2026-4-1">2026.4.1</time>
  <span class="category">学会</span>
  <p>第150回軽金属学会春期大会で口頭発表しました（M2：○○）</p>
</li>
```

| 部分 | 意味 |
|---|---|
| `<li>` | リストの1項目（記事1件） |
| `<time datetime="2026-4-1">` | 機械用の日付（`datetime` 属性） |
| `2026.4.1` | 画面に表示される日付 |
| `<span class="category">学会</span>` | カテゴリバッジ |
| `<p>...</p>` | 本文 |

### パターン②：本文にURLリンクを入れる

```html
<p><a href="https://example.com">学会のページ</a>で口頭発表しました</p>
```

`<a href="...">` と `</a>` で囲まれた部分がリンクになります。

### パターン③：本文の末尾にアルバムリンクを付ける

```html
<p>口頭発表しました（M2：○○）　<a href="album/202604010000/main.html">アルバム</a></p>
```

### パターン④：アルバム一覧の1件分

```html
<li>
  <a href="./album/202604010000/main.html">
    第150回軽金属学会春期大会<br>
    (2026.4.1)<br><br>
    <img src="./album/202604010000/1.jpg">
  </a>
</li>
```

`<br>` は改行です（終了タグ不要）。

## 4. ファイルをVS Codeで開いて編集する

### VS Code のインストール

まだインストールしていない場合は [https://code.visualstudio.com/](https://code.visualstudio.com/) からダウンロードしてください。

### フォルダを開く

1. VS Code を起動する
2. メニュー「ファイル」→「フォルダーを開く」
3. `c:\Users\ryoon\hirosawalab\HP` を選択して「フォルダーの選択」

### ファイルを開く

左のファイルツリーから編集したいファイルをクリックして開きます。

### 文字を検索・置換する

編集したい箇所を見つけるには検索が便利です。

- **検索：** `Ctrl + F`（キーボード）でキーワードを入力
- **置換：** `Ctrl + H` で「検索する文字」→「置換後の文字」を入力

### 保存する

編集後は必ず `Ctrl + S` で保存してください。
タブのファイル名に `●` が付いている間は未保存です。

## 5. よくあるミスとその直し方

### ミス① タグの閉じ忘れ

```html
<!-- NG：</li> がない -->
<li>
  <time datetime="2026-4-1">2026.4.1</time>
  <p>本文テキスト</p>

<!-- OK -->
<li>
  <time datetime="2026-4-1">2026.4.1</time>
  <p>本文テキスト</p>
</li>
```

### ミス② 開始タグと終了タグのタグ名が違う

```html
<!-- NG -->
<p>テキスト</li>

<!-- OK -->
<p>テキスト</p>
```

### ミス③ 属性の引用符が全角になっている

```html
<!-- NG：全角の "" になっている（日本語IMEで入力すると起きやすい） -->
<a href="https://example.com">

<!-- OK：半角の "" -->
<a href="https://example.com">
```

### ミス④ ファイルパスが間違っている

```html
<!-- NG：ファイル名が実際と違う -->
<img src="photo1.jpg">

<!-- OK：実際のファイル名に合わせる -->
<img src="1.jpg">
```

画像が表示されない場合は、まずファイル名のスペルを確認してください。

### ミス⑤ 日本語の全角スペースが混入している

HTMLの属性値や記号は**すべて半角**で書く必要があります。
`datetime="2026-4-1"` の `"` や `-` が全角になっていないか確認してください。

## 6. ブラウザで確認する方法

編集後にブラウザでローカル確認できます。

1. エクスプローラーで `HP` フォルダを開く
2. `News.html` などのファイルをダブルクリック
3. Chrome などのブラウザで表示される

> **注意：** ローカルで見ると一部の動作（tense.js による自動変換など）が動かない場合があります。
> サーバーにアップロード後の確認が最終確認です。

## 7. 実践：ニュース記事を1件追加してみる

実際に手を動かすことで身につきます。以下の手順でやってみてください。

### お題

以下の記事を `News.html` に追加する：
- 日付：2026.5.1
- カテゴリ：学会
- 本文：第149回軽金属学会春期大会で口頭発表しました（M2：○○）

### 手順

**① VS Code で `News.html` を開く**

**② 2026年のセクションを探す**

`Ctrl + F` で `id="2026y"` を検索する。
以下のような箇所が見つかります：

```html
<h2 class="label" id="2026y">2026年</h2>
<ul class="news-list">
  <li>
    <time datetime="2026-3-26">2026.3.26</time>
    ...
  </li>
  ...
</ul>
```

**③ 挿入位置を決める**

日付の降順（新しいものが上）なので、2026.3.26 の `</li>` の直後に挿入します。

**④ 以下のコードを貼り付ける**

```html
        <li>
          <time datetime="2026-5-1">2026.5.1</time>
          <span class="category">学会</span>
          <p>第149回軽金属学会春期大会で口頭発表しました（M2：○○）</p>
        </li>
```

**⑤ `Ctrl + S` で保存する**

**⑥ `News.html` をダブルクリックしてブラウザで確認する**

2026年の欄の先頭に記事が追加されていればOKです。

## まとめ：覚えるべきことは3つだけ

1. **HTMLはタグで囲む** — `<タグ>内容</タグ>` の形
2. **既存のコードをコピーして書き換える** — ゼロから書かなくてよい
3. **検索（Ctrl+F）で目的の箇所を探す** — 大きなファイルも怖くない

この3つを押さえておけば、このサイトの日常的な更新作業は問題なくこなせます。
